# Concept Pitches (2026-09-29) — SET ASIDE

> The project owner asked to go granular instead: discuss game types one at a time before any pitch. Kept for reference only; not canon.

Three concepts grounded in [Inspiration](inspiration.md). All scoped as a 2D first game.

## A. Scrapline
**Top-down extraction runs that feed your own factory.** (Escape From Duckov / ZERO Sievert + Factorio)
Raid a collapsed industrial zone for parts, extract before the storm hits, and feed what you bring home into production lines that build better gear for the next raid. Every raid is tense; every return is satisfying.
- Hits: automation (pattern 1), extraction (2), genre blend (4).
- Risk: two games in one. Biggest scope of the three.

## B. Dead Signal
**A deduction mystery run from a remote relay station.** (The Operator / Obra Dinn + DREDGE)
You're the night operator at an isolated radio relay. Keep the station's machines running while you piece together fragments of intercepted transmissions to work out what happened to a missing crew, and what's out there.
- Hits: deduction (3), eerie genre blend (4), light systems (1).
- Risk: story and puzzle writing is the hard part, not code. Smallest scope.

## C. Hollowmoor
**A cozy automation village in a forest that fights back.** (Oddsparks / Timberborn + Cult of the Lamb + Against the Storm)
Build conveyor-fed workshops with little helper creatures in a cursed wood. Each season the forest reclaims ground, so you expand, defend and push deeper to find out why it's angry.
- Hits: automation (1), cute-but-dark (4), city-builder runs.
- Risk: balancing the pushback so it's never unfair (his Cult of the Lamb gripe).
