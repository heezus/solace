# Jon as a Kith — standalone character study

Jon asked for his own Kith likeness as a separate piece before pairing it with Briana in the title foreground. This is a visual review asset, not a new gameplay character or sprite slot.

![Jon as a Kith](character-v1.png)

The painted design follows his supplied references: dark curls, beard and moustache, friendly smile, geometric left-arm tattoo. Rust orange tunic, cream rolled sleeves, moss sash and leather boots keep the warm earthy Kith identity. The lower three-quarter camera is intended to pair with [Briana's current study](../briana/character-v2.png); head proportions should be checked together before composition.

Original built-in `image_gen` output copied unchanged as `character-v1.png` (1024×1536), with transparent surrounding pixels checked. Private photos remain outside Git. [Prompt and provenance](prompt.json).
